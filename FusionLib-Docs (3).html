FusionLib

A powerful Roblox UI library that merges the best of SimpleLib and Rayfield into one clean, fast package.

🎮 Roblox ⚡ Lightweight 🎨 3 Themes 🔑 Key System 💬 Discord VIP 🔔 Notifications 📊 Progress Bars 🔢 Text Sliders

Installation

Load FusionLib via loadstring from any executor. No extra dependencies needed.

Quick Load

lua
local FusionLib = loadstring(game:HttpGet("https://raw.githubusercontent.com/1easylikebutter1-lgtm/FusionLib/refs/heads/main/FusionLib.lua"))()
ℹ️ Replace the URL with wherever you host FusionLib.lua — GitHub raw, Pastebin, etc.

Minimal Example

lua
local FusionLib = loadstring(game:HttpGet("https://raw.githubusercontent.com/1easylikebutter1-lgtm/FusionLib/refs/heads/main/FusionLib.lua"))()

local Window = FusionLib:CreateWindow({
    Title = "My Script",
    Subtitle = "v1.0",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightShift
})

local Tab = Window:CreateTab({ Name = "Main" })
Tab:CreateButton({ Name = "Hello!", Callback = function()
    print("Button clicked")
end })

Window

The root container. Creates the draggable, resizable window UI with title bar, close, and minimize.

lua
local Window = FusionLib:CreateWindow({
    Title      = "My Script",
    Subtitle   = "v2.0",
    Theme      = "Dark",        -- "Dark" | "Light" | "Midnight"
    Size       = UDim2.fromOffset(580, 420),
    ToggleKey  = Enum.KeyCode.RightShift
})

Config Parameters

ParameterTypeDescription
TitlestringMain title shown in the header
SubtitlestringSmaller subtitle next to the title
Themestring"Dark" / "Light" / "Midnight"
SizeUDim2Window dimensions (default 580×420)
ToggleKeyKeyCodeKey to show/hide the window
💡 The window is draggable by default. Click and drag the title bar to move it anywhere on screen.

Tabs

lua

})

NamestringTab label shown in sidebar

Sections

Visual dividers to group components inside a tab.

lua

ℹ️ Sections show a colored accent line and uppercase label. Place them between groups of related components.

Toggle

An animated on/off switch. Returns a toggle object you can read or set.

lua
local MyToggle = Tab:CreateToggle({
    Name     = "Fly Hack",
    Default  = false,
    Callback = function(state)
        print("Fly:", state)
    end
})

-- Read current value
print(MyToggle.Value)

-- Set programmatically
MyToggle:Set(true)
ParameterTypeDescription
NamestringLabel for the toggle
DefaultbooleanInitial state (default: false)
Callbackfunction(bool)Fires on state change with new value

Dropdown

An animated dropdown with selectable options. Supports dynamic refresh.

lua
local GameDD = Tab:CreateDropdown({
    Name    = "Select Game",
    Options = { "Arsenal", "Blox Fruits", "Murder Mystery 2" },
    Default = "Arsenal",
    Callback = function(option)
        print("Selected:", option)
    end
})

-- Read current
print(GameDD.Value)

-- Set option
GameDD:Set("Blox Fruits")

-- Refresh the options list
GameDD:Refresh({ "New Option 1", "New Option 2" })
ParameterTypeDescription
NamestringLabel for the dropdown
OptionstableArray of string options
DefaultstringInitially selected option
Callbackfunction(str)Fires when an option is selected

Keybind

Let users bind any keyboard key. Click the key box then press any key to assign.

lua
local FlyKey = Tab:CreateKeybind({
    Name     = "Toggle Fly",
    Default  = Enum.KeyCode.F,
    AutoFire = true,   -- auto-trigger callback on keypress
    Callback = function(key)
        print("Key pressed:", key)
    end
})

FlyKey:Set(Enum.KeyCode.G)
ParameterTypeDescription
NamestringLabel for the keybind row
DefaultKeyCodeDefault key assignment
AutoFirebooleanIf true, callback fires whenever that key is pressed
Callbackfunction(KeyCode)Fires when bound key is pressed (if AutoFire)

Notifications

Toast-style notifications shown in the bottom-right corner with auto-dismiss.

lua
FusionLib:Notify({
    Title    = "Script Loaded",
    Content  = "FusionLib is ready to use!",
    Duration = 4,
    Type     = "Success"   -- "Info" | "Success" | "Warning" | "Error"
})

Notification Types

Info

Informational

General messages and updates.

Success

Success

Confirmation that something worked.

Warning

Warning

Non-critical caution notices.

Error

Error

Something went wrong.

ParameterTypeDescription
TitlestringBold heading of the notification
ContentstringBody text (supports wrapping)
DurationnumberSeconds before auto-dismiss (default: 4)
TypestringColor style: Info / Success / Warning / Error

Key System

Blocks script execution until the user enters the correct key. Inspired by Rayfield's key system.

lua
FusionLib:KeySystem({
    Key      = "mySecretKey123",
    Title    = "🔒 Key Required",
    Subtitle = "Enter your VIP key to continue",
    Note     = "Get your key at discord.gg/example"
})

-- Code below only runs after correct key is entered
print("Welcome!")
⚠️ KeySystem yields (pauses) until the correct key is entered. Place it at the top of your script before the rest of your code.
ParameterTypeDescription
KeystringThe correct key string to accept
TitlestringHeader of the key prompt
SubtitlestringInstruction text below title
NotestringFooter note (e.g. where to get the key)

Discord VIP

Shows a Discord invite popup and optionally logs the viewer to a webhook.

lua
FusionLib:DiscordVIP({
    InviteLink = "https://discord.gg/yourserver",
    Webhook    = "https://discord.com/api/webhooks/..."  -- optional
})
💡 The Webhook field is optional. If provided, it sends the player's username and ID to your Discord channel automatically when the VIP popup is shown.
ParameterTypeDescription
InviteLinkstringThe Discord invite URL shown to the user
Webhookstring?Optional Discord webhook URL for logging

Full Script Template

lua – complete example
-- 1. Load
local FusionLib = loadstring(game:HttpGet("https://raw.githubusercontent.com/1easylikebutter1-lgtm/FusionLib/refs/heads/main/FusionLib.lua"))()

-- 2. Key system (optional)
FusionLib:KeySystem({ Key="abc123", Title="VIP Key" })

-- 3. Create window
local W = FusionLib:CreateWindow({
    Title="My Hub", Subtitle="v1", Theme="Dark"
})

-- 4. Tabs
local Main = W:CreateTab({ Name="⚔️ Combat" })
local Misc = W:CreateTab({ Name="⚙️ Misc" })

-- 5. Components
Main:CreateSection("Aimbot")
Main:CreateToggle({ Name="Silent Aim", Callback=function(v) print(v) end })
Main:CreateSlider({ Name="FOV", Min=1, Max=500, Default=100, Callback=function(v) print(v) end })
Main:CreateTextSlider({ Name="Sensitivity", Min=0, Max=5, Default=1, Increment=0.1, Callback=function(v) print(v) end })
Main:CreateDivider()
Main:CreateSection("ESP")
Main:CreateDropdown({ Name="Hit Part", Options={"Head","Torso","Random"}, Callback=function(v) print(v) end })
Main:CreateMultiDropdown({ Name="Show Teams", Options={"Red","Blue","Green"}, Callback=function(t) print(t) end })
Main:CreateColorPicker({ Name="ESP Color", Default=Color3.fromRGB(255,0,0), Callback=function(c) print(c) end })
Main:CreateKeybind({ Name="Toggle Aim", Default=Enum.KeyCode.E, AutoFire=true, Callback=function() print("fired") end })
Main:CreateProgressBar({ Name="Health", Min=0, Max=100, Default=100, Suffix=" HP" })

Misc:CreateButton({ Name="Join Discord", Callback=function()
    FusionLib:DiscordVIP({ InviteLink="https://discord.gg/example" })
end })

-- 6. Welcome notification
FusionLib:Notify({ Title="Loaded!", Content="My Hub is ready.", Type="Success", Duration=4 })

Text Slider

A slider with an editable number box. Users can drag the track or click the box and type a value directly. Supports an optional Increment for decimal steps.

lua
local Speed = Tab:CreateTextSlider({
    Name      = "Walk Speed",
    Min       = 0,
    Max       = 100,
    Default   = 16,
    Increment = 0.5,   -- optional, default 1
    Callback  = function(v)
        game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = v
    end
})

-- Read
print(Speed.Value)

-- Set from code
Speed:Set(50)
💡 Use Increment for decimal precision (e.g. 0.1 for sensitivity sliders). The typed value is automatically clamped and snapped to the increment.

Config Parameters

ParameterTypeDescription
NamestringLabel shown above the slider
MinnumberMinimum value (default 0)
MaxnumberMaximum value (default 100)
DefaultnumberStarting value
IncrementnumberStep size for snapping (default 1)
Callbackfunction(number)Fires whenever the value changes

Returned Object

Field / MethodTypeDescription
.ValuenumberCurrent value
:Set(n)methodProgrammatically set the value (clamps & snaps)

Multi Dropdown

Like a regular dropdown but allows selecting multiple options at once. Selected items are highlighted in the accent color. The callback receives a table (array) of selected values.

lua
local Teams = Tab:CreateMultiDropdown({
    Name    = "Active Teams",
    Options = { "Red", "Blue", "Green", "Yellow" },
    Default = { "Red", "Blue" },   -- pre-selected (table)
    Callback = function(selected)
        -- selected is a table, e.g. {"Red", "Green"}
        for _, v in ipairs(selected) do
            print(v)
        end
    end
})

-- Set selection from code (pass array)
Teams:Set({ "Green" })
ℹ️ .Value is a dictionary (e.g. {Red=true, Blue=true}). The callback gives you a plain array for easy iteration.

Config Parameters

ParameterTypeDescription
NamestringLabel for the dropdown row
OptionstableArray of string options
Defaulttable?Array of pre-selected option strings
Callbackfunction(table)Fires on every selection change; receives array of selected strings

Returned Object

Field / MethodTypeDescription
.Valuedictionary{optionName = true/false} map of selections
:Set(arr)methodReplace selection with a new array of strings

Progress Bar

A read-only animated bar for displaying live values like health, XP, or loading state. Update it from code with :Set() and it smoothly tweens to the new value.

lua
local HP = Tab:CreateProgressBar({
    Name    = "Health",
    Min     = 0,
    Max     = 100,
    Default = 100,
    Suffix  = " HP"   -- appended to the displayed value
})

-- Update from a loop
game:GetService("RunService").Heartbeat:Connect(function()
    local h = game.Players.LocalPlayer.Character
    if h then
        HP:Set(h.Humanoid.Health)
    end
end)

-- Manual update
HP:Set(50)
print(HP.Value)
💡 Use Suffix to label the unit — e.g. "%", " XP", " HP". The bar smoothly tweens on every :Set() call.

Config Parameters

ParameterTypeDescription
NamestringLabel shown above the bar
MinnumberMinimum value (default 0)
MaxnumberMaximum value (default 100)
DefaultnumberStarting fill value
Suffixstring?Text appended to the value display (e.g. "%")

Returned Object

Field / MethodTypeDescription
.ValuenumberCurrent value
:Set(n)methodUpdate the bar (animates smoothly, clamps to Min/Max)

Divider

A simple thin horizontal rule for visually separating groups of components inside a tab. No config needed.

lua
Tab:CreateSection("Combat")
Tab:CreateToggle({ Name="Silent Aim", Callback=function(v) end })
Tab:CreateSlider({ Name="FOV", Min=1, Max=500, Default=100, Callback=function(v) end })

Tab:CreateDivider()   -- ── visual separator ──

Tab:CreateSection("Movement")
Tab:CreateTextSlider({ Name="Speed", Min=0, Max=100, Callback=function(v) end })
💡 Dividers render as a 1-pixel border-colored line. They're great between CreateSection calls when you want extra breathing room without adding a full section header.
